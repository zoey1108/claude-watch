## 描述

抬手看表，点一下屏幕，就学会一个 AI 使用技巧。

AI 一点通是一款专为 Apple Watch 设计的 AI 技巧卡片应用。内置 90 条精心编写的中文技巧，每条都短到一眼就能看完，碎片时间也能慢慢积累。

【内容覆盖】
• 提示词写法：怎么给背景、定任务、给例子，让 AI 回答更准
• Claude Code：斜杠命令、快捷键、计划模式、子代理、Hooks 等实用功能
• Claude 应用：项目、风格、研究模式、Artifacts 等功能怎么用
• API 开发：提示缓存、批量接口、结构化输出等省钱提效的做法

【怎么用】
• 轻点屏幕：换下一条
• 转动数码表冠：翻回刚才看过的
• 长按：收藏喜欢的技巧，随时回看
• 表盘小组件：抬腕就能看到一条
• 每日提醒：每天 1–3 条，定时推送到手腕

【安心使用】
• 完全离线，不需要网络
• 无需注册账号
• 不收集任何个人数据，无广告

本应用为独立开发的非官方学习工具，与 Anthropic 无关联。Claude 是 Anthropic, PBC 的商标。

## 审核备注（App Review Information → Notes）

This is a standalone Apple Watch app (watch-only, no iPhone app). It works fully offline: all 90 tips are bundled in the app, and it makes no network requests. No login is required.

How to test: open the app on Apple Watch, tap the screen to see the next tip, rotate the Digital Crown to go back, long-press to favorite. The gear icon sets daily local tip notifications (0–3 per day). A watch face complication is also included.

This is an independent, unofficial learning tool. It is not affiliated with Anthropic; "Claude" is mentioned only to describe which product the tips are about.

## 中国大陆：申请免除 ICP 备案

本 App 完全离线，可以向苹果申请豁免。提交入口：https://developer.apple.com/cn/contact/ →「App Store Connect」相关问题 → 选与「App 信息 / ICP 备案」最接近的主题。

可直接粘贴的申请内容：

> 您好，我的 App「AI 一点通」（Bundle ID：com.zoey1108.claudetap，Apple ID：〔在 App Store Connect 的 App 信息页查看后填写〕）是一款独立运行的 Apple Watch 应用。应用所有内容均内置在安装包中，完全离线运行，不发起任何网络请求，不连接任何服务器，也没有 App 内购买。根据工信部规定，不提供互联网信息服务的 App 无需办理 ICP 备案，特此申请在中国大陆 App Store 上架时豁免填写 ICP 备案号。谢谢！

提醒：内容主要介绍的是 Claude，而 Claude 目前没有在中国大陆正式提供服务，所以即使拿到豁免，大陆区仍可能在审核时被拒。被拒也不影响其他地区上架。
